# 🍽️ Food Delivery Analytics, Recommendation & Forecasting

## 📌 Project Overview

This project focuses on analyzing food delivery operations, understanding customer ordering behavior, discovering popular food combinations, building a recommendation system, and forecasting future sales.

The goal is to extract meaningful insights from food delivery data using Python, Data Analysis, Machine Learning, Association Rule Mining, and Time Series Forecasting.

## 🎯 Project Objectives

- Analyze food delivery orders and customer behavior.
- Identify popular food items and restaurants.
- Understand revenue patterns across cities.
- Analyze customer ratings and payment preferences.
- Discover frequently purchased food combinations using Apriori.
- Build a food recommendation function.
- Forecast future sales using ARIMA.

## 🛠️ Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- MLxtend
- Statsmodels
- Google Colab / Jupyter Notebook
